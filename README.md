# ONE ORDER

TypeScript・Phaser・Viteを使う、ONE ORDERの開発用リポジトリです。
配置・指示・移動を試すための実験盤を含みます。以下のルールは実験用の仮ルールです。

## 必要な環境

- Node.js 24.x
- npm 11以上（Node.jsに同梱）

Node.jsのバージョン管理ツールを使う場合は、`.nvmrc`の指定を利用できます。

## 起動

リポジトリを取得し、プロジェクトのフォルダで実行します。

```sh
npm ci
npm run dev
```

ブラウザで <http://127.0.0.1:5173> を開きます。
白地の盤面と「配置編集」「実験」の操作が表示されれば起動成功です。
ソースを保存するとViteが変更を反映します。

開発サーバーはターミナルで `Ctrl+C` を押すと停止します。
5173番ポートが使用中の場合は、`npm run dev -- --port 5174` などで変更できます。

## コマンド

| コマンド | 用途 |
| --- | --- |
| `npm run dev` | 開発サーバーを起動 |
| `npm run typecheck` | TypeScriptの型をチェック |
| `npm run build` | 型チェック後、`dist/`に本番用ファイルを生成 |
| `npm run preview` | 本番用ファイルを <http://127.0.0.1:4173> で確認 |
| `npm test` | Vitestを1回実行 |
| `npm run test:watch` | Vitestを監視モードで実行 |

プレビューの前に `npm run build` を実行してください。
`npm test`は、移動・衝突・指示制限・開始配置と履歴の復元を検証します。

## 実験盤の使い方

1. 「配置編集」で盤面の幅・高さ（3〜12）を指定し、「盤面を作成」します。
2. 「操作」で移動・追加・削除を選び、盤面のマスを操作します。移動する駒は、盤上または「選択中の駒」で選びます。
3. 「実験」を押すと、その時点の配置を開始配置として記録します。
4. 駒を選び、空きマスを押して目的地を指示します。「目的地を指定」を押してからマスを選ぶと、駒があるマスにも指示できます。
5. 「1ターン進める」で全員が同時に動きます。駒ごとの現在地・目的地・直前の行動を確認できます。
6. 「1ターン戻す」でターン直前の位置・目的地・指示済みの駒・行動表示を復元します。「開始配置に戻す」で同じ配置から試し直せます。

X・Yの数値入力と操作ボタンでも、盤面上の操作と同じことができます。座標は左上を `(1, 1)` とします。
配置編集へ戻ると、現在位置を残して指示・ターン数・履歴をリセットします。
開始配置と履歴は画面を開いている間だけ保持し、ページを再読み込みすると初期状態に戻ります。

## 実験用の仮ルール

- 初期状態では1ターンに1体へ指示できます。同じ駒の指示はターンを進めるまで修正でき、指示解除も1体分として数えます。
- 指示は変更されるまで継続します。初期状態では上下左右に1マス進み、横方向を先に、次に縦方向へ目的地を目指します。
- 全員の移動候補を同時に判定します。同じマスへの競合、停止している駒への移動、入れ替えや循環移動は停止します。
- 前の駒が空きマスへ進む場合は、後続も同時に進めます。障害物を避ける経路探索はまだ行いません。
- 指示上限・移動量は `src/core/board.ts` の `DEFAULT_RULES` で分離しています。現在は画面上の変更操作を設けていません。

敵・戦闘・地形・学習機能は、この実験盤にはまだ含みません。

## 構成

```text
src/
  main.ts                   # 画面の操作と実験状態の接続
  style.css                 # ページ全体のレイアウト
  core/
    board.ts                # 盤面・指示・同時移動のルール
    board.test.ts           # ルールと境界条件のテスト
    session.ts              # 配置編集・開始配置・ターン履歴
    session.test.ts         # 開始配置とundoの復元テスト
    labels.ts               # 駒の識別名
  game/
    createGame.ts           # Phaserの起動設定
    scenes/
      BoardScene.ts         # 盤面の描画とクリック入力
index.html                  # ブラウザ側の入口
vite.config.ts              # 開発サーバーとビルドの設定
tsconfig.json               # TypeScriptの設定
```

## 依存関係と確認

`package-lock.json`をコミットし、通常の環境準備には `npm ci` を使います。
依存パッケージを追加・更新するときは `npm install` を使い、
`package.json`と`package-lock.json`を合わせて更新してください。

GitHub Actionsでも `npm ci`、`npm test`、`npm run build` を実行します。
`node_modules/`、`dist/`、ローカル設定や検証用ファイルはGit管理に含めません。
