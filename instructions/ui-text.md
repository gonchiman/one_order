# UIの補足テキスト方針

このゲームのUIについて、案を提示するとき、設計するとき、または実装するときに適用する。モックアップや比較案にも同じ方針を適用する。

- 補足テキストは原則として0にする。初期案から説明文・ヒント・操作ガイド・注記を添えない。
- 駒の名前、座標、ターン数、選択状態、指示名、数値、単位、ボタン名、操作結果、入力エラーなど、識別・判断・操作に必要な表示は補足テキストと区別する。必要な名称・値・状態を簡潔に示し、解説文を添えない。
- 説明を添えないと伝わらない場合は、先に名称、項目のまとめ方、配置、操作の流れを見直す。
- 補足テキストを減らす代わりに、ツールチップ、ヘルプ、折りたたみの説明を自動で追加しない。ユーザーが説明の表示を求めた場合は、指定された範囲で追加する。
- 既存UIを再利用するときも、補足テキストの量をそのまま引き継がない。見直しは依頼された範囲に適用し、この方針の追加だけを理由に無関係な画面を一括変更しない。
